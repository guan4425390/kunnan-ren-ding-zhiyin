纸质材料三步走

一

填写申请表（附件2）

  1. 自己打印（2026版），黑色签字笔手写，涂改无效——先打草稿再誊写；
  2. 表头：学校（肇庆医学院）、年级、班别、学（籍）号；
  3. 基本情况：姓名、性别、身份证号、院系、专业；
  4. 特殊群体类型：手里有对应证件的才勾，没有的不要乱勾，拿不准先问辅导员；
  5. 家庭情况按户口本填：户籍地址、所在地类型、成员信息；人均年收入＝家庭年收入总额 ÷ 家庭人口数；
  6. 承诺签字栏：信息核对无误后再签，手工抄写“本人承诺以上所填写资料真实，如有虚假，愿承担相应责任。”＋手写签名＋日期（满16周岁本人签，未满16周岁监护人签）。

附件7 操作指引（重点）

没有启用宏、检查不通过就提交 = 无法汇总 = 等于没交。请严格按下面 5 步操作。
1

用电脑打开

附件7 含宏功能，必须用电脑版 Office Excel 或 WPS 打开，手机无法操作。

2

启用宏（关键）

  • 打开时顶部出现黄色警告条 → 点“启用内容／启用宏”；
  • Excel 没提示：文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 启用所有宏，重新打开；
  • WPS：工具 → 宏 → 安全性 → 启用宏；点“开始检查”无反应，先装“WPS VBA 环境”支持库。
3

填写自己那一行

  • 姓名＝汉字；证件类型＝居民身份证；身份证号18位逐位核对；
  • “是否”类栏目只能填“是”或“否”，不能填数字或打勾；
  • 互斥规则：特困救助 / 特困职工 / 低保 / 低保边缘 / 刚性支出，只能其中一项“是”，其余必须“否”；
  • 家庭年收入填数字（单位：元）。
4

点“开始检查”直到 0 错误

填完点表格里的“开始检查”按钮。通过 → 立即保存；有错 → 按提示逐条改正，重复检查直到完全通过。

5

命名提交

文件重命名为“班级＋姓名＋学号”，9月19日（周六）24:00 前发给班长。

班长专栏

  1. 收齐全班附件7单表后，把每个人的数据行逐行合并到一份附件7总表（一行一人，不动表头和公式结构）；
  2. 打开总表，同样点“开始检查”，确保 0 错误；
  3. 按模板填好一份附件6汇总表（全班申请名单）；
  4. 组织召开班级评审会议：填写《评审会议记录表》，拍照留存并记录会议内容，作为班级评审依据——每位班长均需提交此表；
  5. 9月21日（周一）一早：两个总表（附件6＋附件7）＋全班纸质材料＋评审会议记录表与会议照片，统一交辅导员。
最终交付物 = 两个总表：1 份附件6汇总表 ＋ 1 份附件7总表。个人单表只作收集用。
评审会议记录表＋会议照片缺一不可：即使未实际召开会议，只要班里有同学提交材料，也必须补齐“评审记录表＋照片”两项材料。

特别提醒

  1. 顺序一致：纸质材料排放顺序与附件7填写顺序一致；
  2. 宏必须启用：附件7 检查不通过就交 = 等于没交；
  3. 手写承诺：承诺语本人手抄，不要打印，核对无误后再签；
  4. 放弃要走程序：特殊群体自愿放弃须交附件1（签名＋按手印），学年更正为“2026—2027学年”；
  5. 材料必须真实：提供虚假佐证材料将影响认定结果和个人诚信记录；
  6. 评审会议记录表：由班长组织填写并拍照留存，作为班级评审依据；未实际召开会议也必须补齐记录表＋照片两项材料。
  7. 认定含班级评议、学院审核公示等环节，材料按《认定分析表》逐一核查，请放心如实申报。
